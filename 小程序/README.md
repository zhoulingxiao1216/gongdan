# 附加项报工原型

双击 `index.html` 用浏览器打开。无需安装、构建或后端。

- `index.html`：可交互的小程序中保真原型，桌面含评审演示台。
- `需求评审说明.md`：按用户要求的六部分组织，包含逐页设计、业务规则、来源映射、假设与未覆盖项。
- `验证记录.md`：37 项逻辑测试结果及实际浏览器验证限制。
- `verify.js`：逻辑测试用最小 DOM 替身，不是浏览器自动化脚本。

快速演示：扫码 DDEMO001 → 贴纸补报 2 件 → 模拟正品 +2 → 再补报 2 件 → 查看历史记录。

其他场景：DDEMO002 无附加项；DDEMO003 无正品。右侧评审台可模拟数量减少、他人报工、提交失败、预览失败或预览文件未生成。移动端评审工具位于工作台/商品页下方。

所有数据为模拟；上传图片仅保存在本浏览器。没有真实扫码、打印、上游处置或尾检放行。正式实现应移除评审控件。
