# PC 质控报工 HTML 原型

直接用现代浏览器打开 [index.html](index.html)。不需要安装依赖、构建或后端。

保持当前目录结构，商品缩略图引用上一级的 `代购订单详情页.png`。建议在 1920×1080 或 1366×768 屏幕查看。

## 页面入口

- 初始进入代购订单列表，可筛选、翻页并进入订单详情。
- 商品行“附加项报工”打开报工抽屉；“查看配置”和“到货数量”分别展示原页面的只读参考。
- 左侧拆成“质控附加项报工”和“发货单报工”两个模块。
- 质控附加项报工包含报工工作台、员工产量、报工明细，只统计入库前附加项记录。
- 发货单报工包含发货单报工产量、报工明细，只统计发货单绑定的 PDA 配货、打包、箱规完成、发货确认记录。
- 右上角“演示工具”可设置上游数量变化、模拟小程序来源、提交异常和预览异常。
- 代购订单详情入口的报工记录只展示附加项报工，不展示 PDA 入库、配货、打包、箱规完成、发货确认。

## 建议走查

1. 打开第一个订单，进入 DDEMO001 的报工抽屉。
2. 贴纸正品8、累计5、剩余3，填3并确认实际处理人后提交。
3. 查看质控附加项报工下的员工产量，点“查看明细”核对新增记录。
4. 工作台查询 DDEMO001，验证与抽屉共用累计。
5. 模拟正品+2，验证只开放增量，不自动计入人员产出。
6. 选择贴纸、吊牌、洗标、FBA 分别预览；图片凭证可选择本地演示图片测试。
7. 查询 DDEMO003（无正品）或 DDEMO004（无附加项）。
8. 进入发货单报工产量，查看 SHIP-DEMO-001 的 PDA 配货、打包、箱规完成、发货确认产量。

## 数据与边界

数据尝试保存到当前浏览器 localStorage；若存储不可用或已满，页面会提示仅当前打开期间保留。可在演示工具重置。本原型使用独立存储键，不修改旧小程序 HTML 的数据。

PC工作台与订单抽屉真实共用本原型内的账本；其中“小程序”记录为演示来源，并未与旧小程序HTML或生产后端连接。报工不改清算金额或完成状态。标签是DEMO预览，不是生产文件。

CSV导出仅导出当前展示结果，不是工资或清算报表。质控附加项报工的订单号为代购订单号；发货单报工的订单号为发货单号。检品方式四个选项只读展示到货基数，其他已选附加项按正品上限报工。

报工明细支持删除附加项报工记录，删除后对应商品附加项的累计已报数量会回退。发货单报工中的 PDA 来源记录只展示，不在 PC 报工明细页直接删除，应由来源业务系统做冲销或更正。
